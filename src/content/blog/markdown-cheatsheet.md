本站的文章全部用 **Markdown** 书写——一种用简单符号标记格式的纯文本语法。这一页就是速查表。

## 标题

```md
# 一级标题
## 二级标题
### 三级标题
```

## 强调

```md
**加粗**
*斜体*
~~删除线~~
```

## 列表

```md
- 无序列表项
- 无序列表项

1. 有序列表项
2. 有序列表项
```

## 链接和图片

```md
[链接文字](https://example.com)
![图片说明](/favicon.svg)
```

## 引用

```md
> 这是一段引用
```

## 代码

## 写作流程

1. 在 `src/content/blog/` 新建一个 `.md` 文件
2. 顶部写 frontmatter（标题、日期、分类、标签）
3. 正文用 Markdown 写
4. 保存后浏览器自动刷新

就这么简单——**内容即文件**。
